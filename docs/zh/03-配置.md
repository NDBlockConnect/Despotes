# Despotes 配置

> 文档 3 / 4 | Despotes 文档集 > 版本：v26.0
> 规范语言为英文，见 [03-Configuration.md](../03-Configuration.md)

Despotes 从**游戏目录**（包含 `options.txt` 的目录）读取 **`despotes.json`**。首次启动生成默认值，文件变更时自动重载（每 5 秒轮询；也可经 `POST /despotes/v1/config/reload` 重读）。

## 1. 完整参考（默认值）

## 2. 外源控制来源

`sources` 是已配置控制来源的列表。内置传输：`http`、`cli`、`filedrop`。一个来源生效需要**同时**满足其 `enabled` 标志与其传输段启用。

插件来源（v26.1+）添加 `"transport": "plugin"` 与 `"class"` 字段的条目，`class` 为类路径上的 `ControlSourceFactory` 实现名：

```json
{ "id": "my-ws", "transport": "plugin", "class": "com.example.WsSourceFactory",
  "config": { "...传输专属配置..." }, "enabled": true }
```

## 2.5 焦点与鼠标捕获

原版 Minecraft 在窗口失去系统焦点时从不释放被捕获的鼠标光标，因此即使你在操作其他窗口，游戏仍会锁定鼠标。Despotes 解决了这个问题：

- `focus.releaseMouseOnFocusLoss`（默认 `true`）——每当游戏窗口失去系统焦点时，Despotes 将已捕获的光标释放回桌面（仅在光标被捕获时执行）。
- `focus.regrabMouseOnFocusGain`（默认 `true`）——焦点恢复时，若失焦前光标处于捕获状态，则自动重新捕获。

可随时通过 `mouse` 动作（文档 02 §2.8）手动控制。外源注入的输入从不要求窗口处于焦点状态，也绝不触碰用户的系统鼠标与键盘。

## 3. 安全说明

- `security.allowSources` 是允许发出命令的额外对端地址列表（如 `"192.168.1.50"`）。回环地址始终允许。
- `security.requireToken` 为 true 时，每个请求必须携带 `X-Despotes-Token: <token>`（HTTP 头 / CLI 字段 `"token"`）。
- 修改 `http.port` 在重启或配置重载后生效。

## 4. 优先级

1. `security.enabled=false` 覆盖除 CLI 外的一切。
2. 传输段覆盖单个来源条目。
3. 命令行系统属性 `-Ddespotes.port=NNNN` 覆盖 `http.port`（调试用）。
