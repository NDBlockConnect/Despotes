# Despotes 版本管理

> 文档 4 / 4 | Despotes 文档集 > 版本：v26.12
> 规范语言为英文，见 [04-Versioning.md](../04-Versioning.md)

Despotes 遵循 Aprism 版本方案（Aprism 文档 §12.1），并按模组情况适配：

## 1. 方案

```
v<年份>.<小版本>[-Alpha.<n>][-<加载器>-<MC版本>]
```

- 大版本线对应自然年：`v26` = 2026 年，小版本 `v26.0` … `v26.9`。
- 小版本内：`Alpha.1` … `Alpha.9`，每个以 **GitHub Pre-Release** 发布。最后一个 Alpha（Alpha.9）即发布候选。
- 小版本正式版为裸版本号（如 `v26.0`），以 **GitHub Release** 发布。
- 不设 Beta 渠道。

## 2. 产物命名

发布产物按加载器与 Minecraft 版本命名：

```
Despotes-v26.0-Alpha.1-fabric-26.2.jar
Despotes-v26.0-Alpha.1-neoforge-1.21.1.jar
Despotes-v26.0-Alpha.1-forge-1.21.1.jar
Despotes-v26.0-Alpha.1-native-1.21.4.jar
Despotes-v26.0-Alpha.1-aprism-26.2.aje
```

每个 GitHub release 包含该周期构建的全部产物与一份 `RELEASE_NOTES.md`。

## 3. 加载器分支

按 Aprism §12 分支规范：每加载器一个分支 —— `fabric`、`neoforge`、`forge`、`native`、`aprism` —— 外加 `main`（仅文档/规范）。标签从各加载器分支切出；一次发布聚合同一版本下所有加载器分支的产物。

## 4. 各大版本线的 Minecraft 支持（v26.0 最小目标）

| 加载器 | MC 范围 |
|---|---|
| native | 1.20 – 26.2 |
| fabric | 1.20 – 26.2 |
| neoforge | 1.20.1 – 26.2 |
| forge | 1.20 – 1.21.4 |
| aprism | 26.1 – 26.2（Aprism Loader v26 线） |

## 5. 接口契约

控制协议与 `despotes.json` schema 单调递增：字段可新增或弃用（保留至少一个 LTS 周期），v26 线内不移除、不重命名。
