# Despotes v26.0-Alpha.9 (Pre-Release · Release Candidate)

> In-process local control channel for Minecraft: Java Edition. External sources drive the
> game without ever touching your keyboard or mouse.
> This is the release candidate for the v26.0 minor line.

## Highlights

- **Release-candidate stamp**: same eleven-artifact matrix as Alpha.8, rebuilt and
  regression-tested (26.2 Fabric re-verified in-game this cycle: status / GUI clicks /
  screenshots while unfocused).
- No functional changes since Alpha.8; this cycle focused on regression across the
  verified lines (Fabric 26.2 / 1.21.4 / 1.21.1 / 1.20.1, NeoForge 26.2 / 1.21.1,
  Native 26.2).
