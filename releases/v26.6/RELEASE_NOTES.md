# Despotes v26.6 (Stable Release)

> In-process local control channel for Minecraft: Java Edition.

Stable release of the v26.6 line — Combat System.

## What's new since v26.5

### Combat System

- **`attack-entity`** action: attack an entity by UUID (look at it, then attack next tick)
- **`combat`** query: nearby hostile mobs and projectiles (reuses threats probe)
- **`retreat`** action: flee from nearest threat using navigation
- **`shield`** action: raise/lower shield via useItem
